GERMAN:
Mein zweites Java Project auf GitHub. Eine sehr simple To-Do-Liste. Nichts aufregendes, aber ich konnte dadurch nochmal andere Layouts ausprobieren und mehr Erfahrung mit Swing sammeln.
Funktionen:
Man kann beliebig viele Aufgaben erstellen und, wenn erledigt, abhaken. (Wie viele man tatsächlich erstellen kann, weiß ich nicht...).
Natürlich kann man auch die Aufgaben löschen. Hierzu drückt man den "Löschen" Knopf unten, wodurch sich der "Läschen Modus" aktiviert. Nun muss man nur noch die Checkbox vor dem Text drücken und die Aufgabe wird gelöscht.
Beim erneuten drücken des "Löschen" Knopfes wird der "Lösch Modus" deaktiviert.

ENGLISH:
My second Java project on GitHub. A very simple to-do list. Nothing exciting, but I was able to try out other layouts and gain more experience with Swing.
Functions:
You can create as many tasks as you like and check them off when they're done. (I don't know how many you can actually create...).
Of course you can also delete tasks. To do this, press the “Delete” button at the bottom, which activates the “Delete mode”. Now you just have to press the checkbox in front of the text and the task will be deleted.
When you press the “Delete” button again, the “Delete mode” is deactivated.
